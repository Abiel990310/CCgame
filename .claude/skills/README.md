# Agent skills

Copied from public repos so every Claude session on this repo, cloud threads
included, can load them. They are reference material: when one disagrees with
CLAUDE.md (for example by suggesting a web font, a CDN, `Math.random` in
`shared/`, or a UI library), CLAUDE.md wins.

| Skills | Source | Licence |
| --- | --- | --- |
| `pixijs*` (v8) | https://github.com/pixijs/pixijs-skills | MIT, `LICENSE-pixijs` |
| game-feel, game-ui-ux, audio-design, performance-optimization, procedural-gen, camera-systems, save-systems, level-design, game-ai, input-systems, survival-crafting, tower-defense, steam-publish | https://github.com/gamedev-skills/awesome-gamedev-agent-skills | Apache-2.0, `LICENSE-gamedev`, `NOTICE-gamedev` |
| frontend-design, algorithmic-art, webapp-testing | https://github.com/anthropics/skills | Apache-2.0, `LICENSE.txt` in each folder |

To update one, copy its folder again from the source repo.
